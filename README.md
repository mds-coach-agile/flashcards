# Study Flashcards (Flashcards de Estudo)

An interactive, responsive web application for studying with flashcards.

## Features
- 10 curated flashcards (`flashcards.json`) with front/back and key takeaways
- Smooth 3D card flip on click (or `Space` / `Enter`)
- Mark each card as **Known** or **To Review**
- Fisher-Yates deck shuffling
- Real-time progress bar and Known / To Review counters
- End-of-session summary with mastery percentage, card breakdown, **Restart Full Deck**, **Practice "To Review"**, and **Shuffle & Restart**
- Light & Dark theme toggle and responsive mobile layout

## Running Locally
Open `index.html` in a browser or serve locally:

```bash
python3 -m http.server 8000
```
